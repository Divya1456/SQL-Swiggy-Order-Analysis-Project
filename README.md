I have worked on a SQL-based analytics project using food ordering app data to understand customer ordering patterns and outlet performance. I have analysed latest customer orders, outlet-wise and cumulative order counts, total and cumulative bill amounts, and order status summaries. I have also created customer–outlet crosstab reports to evaluate order volume and sales contribution. To achieve this, I have used advanced SQL concepts like CTEs, Joins, Aggregations Group By, Caste Statements. Finally, I have exported the result sets and consolidated them into a structured report to support business insights and decision-making.
